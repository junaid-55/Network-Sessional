------------------------------------------------------------------------------
1. WHAT IS WIRESHARK?
------------------------------------------------------------------------------
- Free, open-source network protocol analyzer
- Captures and analyzes network traffic in real-time
- Supports hundreds of protocols
- Cross-platform (Windows, Linux, macOS)

------------------------------------------------------------------------------
2. INTERFACE OVERVIEW
------------------------------------------------------------------------------
- Packet List Pane: Shows all captured packets
- Packet Details Pane: Shows protocol layers of selected packet
- Packet Bytes Pane: Shows raw hex data
- Filter Toolbar: Apply display filters
- Capture Interface List: Select network interface

------------------------------------------------------------------------------
3. STARTING A CAPTURE
------------------------------------------------------------------------------
- Select interface (Wi-Fi, Ethernet, Loopback, etc.)
- Click shark fin icon (blue) to start
- Click red square to stop
- Ctrl+E: Start/Stop capture

------------------------------------------------------------------------------
4. BASIC KEYBOARD SHORTCUTS
------------------------------------------------------------------------------
Ctrl+E          - Start/Stop capture
Ctrl+K          - Capture options
Ctrl+O          - Open capture file
Ctrl+S          - Save capture file
Ctrl+W          - Close capture file
Ctrl+F          - Find packet
Ctrl+G          - Go to packet number
Ctrl+N          - Next packet
Ctrl+B          - Previous packet
Ctrl+Shift+P    - Preferences
Space           - Toggle packet mark
Ctrl+M          - Mark/Unmark packet
Ctrl+Right      - Next packet in conversation
Ctrl+Left       - Previous packet in conversation

36. SECURITY ANALYSIS FILTERS
------------------------------------------------------------------------------
# Possible attacks
tcp.flags.syn == 1 and tcp.flags.ack == 0   - SYN scan/flood
icmp.type == 8 and ip.src == ip.dst         - Smurf attack indicator
arp.duplicate-address-detected              - ARP spoofing
tcp.port == 4444                            - Default Metasploit
http.request.uri contains "cmd="            - Command injection
http.request.uri contains "SELECT"          - SQL injection attempt
http.request.uri contains "<script"         - XSS attempt

# Suspicious traffic
tcp.port == 6666 or tcp.port == 6667        - IRC (botnet common)
tcp.port == 31337                           - Back Orifice
tcp.port == 12345                           - NetBus
dns.qry.name contains "dyndns"              - Dynamic DNS (C2 common)
http.user_agent contains "curl"             - Automated tools
http.user_agent contains "python"           - Scripted access

41. COMMON TSHARK EXAMPLES
------------------------------------------------------------------------------
# Extract all HTTP hosts
tshark -r file.pcap -Y "http.request" -T fields -e http.host | sort -u

# Extract all DNS queries
tshark -r file.pcap -Y "dns.qry.name" -T fields -e dns.qry.name | sort -u

# Count packets per IP
tshark -r file.pcap -T fields -e ip.src | sort | uniq -c | sort -rn

# Extract HTTP URIs
tshark -r file.pcap -Y "http.request" -T fields -e http.request.full_uri

# Follow TCP stream to file
tshark -r file.pcap -q -z "follow,tcp,ascii,0"

================================================================================
                          TROUBLESHOOTING GUIDE
================================================================================

Problem: High latency
Filters: tcp.analysis.ack_rtt > 0.2
         frame.time_delta > 0.5

Problem: Packet loss
Filters: tcp.analysis.retransmission
         tcp.analysis.duplicate_ack
         tcp.analysis.lost_segment

Problem: Connection failures
Filters: tcp.flags.reset == 1
         icmp.type == 3
         tcp.flags.syn == 1 and tcp.flags.ack == 0

Problem: Bandwidth hog
Check:   Statistics > Conversations (sort by bytes)
         Statistics > Endpoints

Problem: DNS issues
Filters: dns.flags.rcode != 0
         dns.time > 0.5

Problem: Slow web browsing
Filters: http.time > 1
         dns.time > 0.5
         tcp.analysis.retransmission

------------------------------------------------------------------------------
BEGINNER PRACTICE PROBLEMS
------------------------------------------------------------------------------

7. Filter for all traffic on port 443 (HTTPS)

8. Display only ARP request packets

9. Show all packets larger than 1000 bytes

10. Filter for HTTP GET requests only

INTERMEDIATE PRACTICE PROBLEMS
------------------------------------------------------------------------------

11. Find all failed DNS lookups (NXDOMAIN responses)

12. Show TCP retransmissions from a specific IP (192.168.1.100)

13. Display HTTP responses with error codes (4xx and 5xx)

14. Filter for new TCP connections (SYN without ACK) to port 22
